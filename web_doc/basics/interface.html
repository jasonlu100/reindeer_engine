认识编辑器界面

打开 Reindeer Engine 后，你会看到类似 Godot 的布局。从上到下、从左到右依次是这些区域：

区域作用
菜单栏文件、场景、编辑、设置、导出、帮助等全局操作。其中 帮助 → 教程 可以重新打开本教程。
主工具栏运行 / 停止 / 保存 / 撤销 / 前进 等快捷按钮。
场景树（Scene）左侧，展示当前场景的节点层级结构。右键节点可添加子节点、复制、删除。
检查器（Inspector）右侧，显示选中节点的所有可编辑属性，并可为节点指定脚本。
文件系统（FileSystem）左下，浏览项目里的脚本、场景、贴图、文件夹，可新建 / 打开 / 删除。
视口（Viewport）中央，所见即所得的编辑画布，运行时会实时预览。
调试面板（Debug）底部，运行时显示 FPS、节点数、刚体数等信息。
状态栏最底部，显示就绪状态、节点数量与未保存标记。
小技巧：选中场景树里的节点，右侧检查器会立刻显示它的属性；双击文件系统里的 .reindeer.tscn 即可打开对应场景。

逐个辨认编辑器面板

下面把每个区域的位置、名称、功能讲清楚，尤其是经常被混淆的“场景树”和“文件系统”。

中央视口（Viewport）

所见即所得的编辑画布，渲染当前场景；点击 ▶ Play 时实时预览运行效果。交互：左键拖拽移动选中的节点；中键拖拽平移视图；滚轮缩放视图；空白处左键单击取消选择。

左侧：场景树（Scene 树）

列出当前打开场景的节点层级（一个根节点 + 若干子节点）。在这里可以选中节点、右键添加子节点、复制、删除、拖拽调整父子关系。它只反映“内存中当前场景的节点结构”，显示的是节点对象而非文件。

右侧：检查器（Inspector）

显示当前选中节点的全部可编辑属性（由节点的 PROPERTIES 元数据自动生成控件），并可为节点附加 .py 脚本文件。

左下：文件系统（FileSystem）

浏览磁盘上工程目录里的文件与文件夹：.reindeer.tscn 场景文件、.py 脚本、图片贴图、音频等。右键可新建脚本 / 场景 / 文件夹；双击 .reindeer.tscn 会在视口与场景树中打开该场景。

底部：调试面板（Debug）

实时显示 FPS、节点数、物理刚体数，以及脚本 print 输出的日志。

重要辨析：场景树 ≠ 文件系统

这是新手最容易混淆的两块，请务必分清。它们一个是“节点树”，一个是“文件浏览器”：

对比项场景树（左侧）文件系统（左下）
显示内容当前打开场景的节点层级（内存中的节点对象）硬盘上工程的文件（.reindeer.tscn、.py、图片等）
本质节点树文件浏览器
常见操作选中 / 增删 / 拖拽节点新建 / 打开 / 删除文件；双击 .reindeer.tscn 打开场景
二者关系在文件系统里双击 .reindeer.tscn → 加载场景 → 其节点才出现在场景树里
不要把文件系统说成场景树，也不要把文件（.tscn / .py）说成节点。两者是“文件”和“节点”的区别。

常见易错点

  • 场景树（左侧，节点）≠ 文件系统（左下，磁盘文件）。这是最高频的错误。
  • Node2D 的 position 是相对父节点的局部坐标；要世界坐标用 get_global_position()。
  • 输入用“动作(action)”而非硬编码按键；ui_left 等内置动作始终可用，自定义动作在 设置 → 工程设置 → 输入映射 绑定。
  • 给节点加脚本是在“检查器”里指定 .py 文件，不是在文件系统里双击。
  • Camera2D 跟随：作为玩家子节点最省事；单独放时需每帧更新其 global_position。
