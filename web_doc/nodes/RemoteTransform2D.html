远程变换 RemoteTransform2D

Node2D

把本节点的全局变换实时“推送”给另一个节点，实现节点之间的变换联动。

详细说明

每帧把本节点的全局 position / rotation / scale 同步到 remote_path 指向的目标节点（自动换算成目标相对于其父节点的局部值）。可用 use_position / use_rotation / use_scale 分别开关要同步的轴。目标必须是拥有 position/rotation/scale 的节点（Node2D 及其子类）。

典型用途

  • 让一个影子 Sprite2D 跟随玩家（把影子设为 remote）；
  • 多个物体共享同一条移动轨迹；
  • 做镜像 / 复制运动。
