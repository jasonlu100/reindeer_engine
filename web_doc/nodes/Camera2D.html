相机 Camera2D

Camera

决定视口“看到”的世界范围；场景里第一个 current=true 的相机生效。

详细说明

current 是否启用；zoom 缩放（>1 放大）；offset 镜头偏移；smoothing 平滑跟随；limit_x/limit_y 限制镜头中心的范围（防止看到地图外）。

典型用途

  • 跟随玩家；
  • 镜头拉近 / 拉远；
  • 用 limit 锁死关卡边界。

小示例

# 跟随玩家：把 Camera2D 设为玩家子节点即可自动跟随
💡 多个相机时，只有 current=true 的那个生效；想切镜头就改各相机的 current。
💡 开启 smoothing 后，相机每帧朝目标 lerp 逼近；所有视差（ParallaxBackground / ParallaxObject）都基于相机缓动后的渲染中心计算，因此背景与远近视差会自然跟随缓动镜头平滑滞后——不会出现“视差仍用原始移动”的违和感。
提示：所有节点都继承 name / visible 两个通用属性；Node2D 及其子类额外拥有 position / rotation / scale / modulate / z_index。
