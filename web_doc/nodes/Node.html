节点 Node

Node

场景树中最基础的节点，所有其它节点都继承自它。

详细说明

Node 是场景树的原子单位。它本身没有 2D 变换（位置/大小由子类 Node2D 提供），但提供 name、visible 两个通用属性，以及 _ready/_process 等生命周期与信号。你通常不直接使用裸 Node，而是使用它的子类。

典型用途

  • 作为“纯逻辑容器”或组织节点；
  • 挂载只处理逻辑、不需要渲染的脚本；
  • 用 visible 统一开关一整棵子树（勾掉后子节点都不显示，但脚本照常运行）。
