第 9 阶段

视差、相机缓动与节点配合

这一节把前面零散的能力串起来：让**视差背景跟随相机缓动**、用 z_index 管遮挡层次，并认识一批**专门用来配合其它节点**的“合作节点”。

1. 视差跟随相机缓动

之前视差背景 / 物体用的是相机的原始位置，开启相机 smoothing 缓动后会出现“视差仍用正常移动”的违和感。现在视差统一改用相机的渲染中心（含 smoothing 缓动与 limit 边界钳制）——开启缓动后，背景与远近物体会随缓动后的镜头平滑滞后移动。

搭建一个会缓动的纵深场景：
  • 根下挂 Camera2D，勾选 smoothing，并把它设为玩家子节点（自动跟随）；
  • 根下挂 ParallaxBackground（texture=云，parallax=0.2）当作最远层；
  • 放几个 ParallaxObject，分别设 depth=0.3（远山）、0.7（近树），继承 Sprite2D 可换贴图；
  • 运行并用方向键移动玩家——你会看到云最慢、远山次之、近树最快，且整体随缓动镜头平滑跟随。
💡 ParallaxObject 不用挂在 ParallaxBackground 下，它自己读活动相机计算视差；勾选 perspective 还能得到近大远小。

2. 用 z_index 管理遮挡层次

z_index（Node2D）与 CanvasLayer.layer 都已真实生效。绘制顺序按 (CanvasLayer.layer, z_index, 场景树顺序)：想让某个精灵永远在最前，就调大它的 z_index，或放进更大的 CanvasLayer（典型用法：把 HUD 放进 layer=10 的 CanvasLayer，永远盖在世界之上）。

3. 节点间配合：合作节点

引擎内置一批专门“配合”其它节点的节点 / 系统，把单个能力串成完整玩法：

  • RemoteTransform2D（Node2D）：把本节点的全局变换实时推送给另一个节点——让影子 Sprite2D 跟随玩家、多个物体共享同一条轨迹。分别用 use_position/use_rotation/use_scale 开关。
  • Joint2D（Physics）：把两个 RigidBody2D 用约束连起来协同运动。joint_type=spring 像弹簧/绳子，pin 像链条/摆锤；用 node_a_path/node_b_path 指向两个刚体，引擎自动建立约束。
  • Spawner（Node）：按 interval 实例化一个 .tscn 场景并作为子节点，超过 max_instances 自动释放最旧实例（对象池）；生成物可自动加入 group，配合 get_nodes_in_group/call_group 批量控制。
  • 分组系统：add_to_group(name) 打标签，再 get_nodes_in_group(name)/call_group(name, 方法) 批量操作——比如一发 call_group("enemies","take_damage",10)。
提示：合作节点用“节点路径”指向目标（可填绝对路径如 /root/Player 或相对路径 ../Target）。

4. 综合示例：会缓动的纵深 + 批量敌人

# 敌人脚本：进入场景时加入 "enemies" 分组，并跟随玩家影子
func _ready():
    self.add_to_group("enemies")

# 主场景里用 Spawner 生成敌人（scene=enemy.tscn, interval=1.5, group="enemies"），
# 需要全体扣血时：
self.call_group("enemies", "take_damage", 10)
# 视差 + 缓动：相机 smoothing 开启后，ParallaxBackground/ParallaxObject 自动平滑滞后。

把上述能力组合起来，你就能做出既有景深、又随缓动顺滑、还能批量管理敌人的完整关卡。
